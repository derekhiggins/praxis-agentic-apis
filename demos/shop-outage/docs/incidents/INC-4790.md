# Incident report INC-4790: intermittent 502s from payments-gateway

Severity: SEV2
Status: resolved
Duration: 3 days intermittent
Services: payments-gateway

## Summary

About 0.5% of card authorization calls returned 502 from the OpenShift router.
Requests that sat idle on a keep-alive connection longer than 30 seconds were
closed by the router while payments-gateway still considered them open.

## Resolution

Set the route annotation `haproxy.router.openshift.io/timeout: 60s` and lowered
the payments-gateway keep-alive to 25 seconds.

## How to tell it apart

Router 502s are intermittent and spread across all endpoints. A full checkout
outage with every request failing is not this issue.
